A1 · 新增控件导入目标路径

位置：任务列表下方、输出路径上方（与任务组同层级——它是全局设置，对所有任务组生效，不占用已经拥挤的任务行）。样式与「输出路径」完全一致（标签 78px + 输入框 + 浏览 + 重置），符合现有 MakeInputRow 节奏。

默认值/Game/CaptureManager/Imports（与现状一致，老用户零学习成本） 自动子目录实际落位 {路径}/{批次名}/{take}，批次名取表演源末级目录，与现有镜像逻辑一致 重置按钮 ⟲一键恢复默认值，防误改后找不到素材 留空行为等价默认值（不报错，hint 里说明）

A2 · 重名检测防误覆盖

提交任务时（开始解算/一键预检）对每个任务组扫描目标路径下的既有资产，与待导入 take 比对：

无重名正常推进，日志提示导入目标全路径（见上方日志第 3 行演示） 完全一致视为已导入，走现有幂等跳过（不重复导入） 重名不一致黄色警告条逐条列出（见上方演示），该 take 跳过导入——绝不静默覆盖；用户换路径或删旧资产后重跑

检测在预检阶段完成（秒级，AssetRegistry 查询），不会等到几十分钟的解算阶段才暴露。
