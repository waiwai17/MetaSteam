# 傻瓜步骤（照着复制粘贴就能跑通）

> 全程**不用手动建工程、不用拖 Python 文件、不用放插件**。
> 唯一需要你动手的：装 2 个软件 + 在 UE 里做一次身份。

---

## 第 0 步：装两样东西（只需一次）

1. **Unreal Engine 5.7** —— 安装/新建工程时确保 **MetaHuman 插件已启用**
2. **Python 3.9+** —— 官网下载安装，**务必勾选 "Add Python to PATH"**

验证装好了（命令行里执行，都有输出即 OK）：
```
python --version
```

---

## 第 1 步：取代码

```
git clone https://github.com/waiwai17/MetaSteam.git
cd MetaSteam
```

---

## 第 2 步：一键建工程（复制粘贴，把路径换成你想要的）

```
cd deploy\tools
python launcher.py init --name MH_Line01 --dir D:\MetaSol
```

它会**自动**：探测本机 UE → 复制模板工程（自带插件，免编译）→ 复制引擎 Python 代码 →
建热文件夹 `MH_Line01_inbox\{am,pm,_id}` 和导出目录 `MH_Line01_out` → 写配置。

执行完会打印这几行，**记下来**（下一步要用"热文件夹"）：
```
[INFO] 工程  : D:\MetaSol\MH_Line01\MH_Line01.uproject
[INFO] 热文件夹: D:\MetaSol\MH_Line01_inbox
[INFO] 导出  : D:\MetaSol\MH_Line01_out
```

> 如果它说找不到 UE：手动指定
> `set MHS_UE_EDITOR=D:\UE_5.7\Engine\Binaries\Win64\UnrealEditor.exe` 后再重跑。

---

## 第 3 步：放测试素材（自动下载好的 am/pm 两条演员 ID）

回到仓库根目录执行（把路径换成上一步的"热文件夹"）：
```
cd ..\..
python tests\fixtures\make_testset.py --out D:\MetaSol\MH_Line01_inbox
```

结果：
```
MH_Line01_inbox\_id\0818_face_rom_am_001_11\   ← 上午(am) 演员
MH_Line01_inbox\_id\0818_face_rom_pm_001_9\    ← 下午(pm) 演员
MH_Line01_inbox\am\   MH_Line01_inbox\pm\      ← 表演素材放这里（下一步）
```

> 想连表演素材一起准备（本机需有素材库）：
> `python tests\fixtures\make_testset.py --out <热文件夹> --with-perf --source E:\Work\Mobu_maya\SSV_Test\Facial_Data`

---

## 第 4 步：预检（必须看到 errors 为空）

```
cd deploy\tools
python launcher.py doctor --config pipeline.config.json
```

- 看到 `errors: []` → **继续第 5 步**
- 看到"工程缺少 MetaHuman 资产" → 执行（自动在本机找已有 MetaHuman 资产并收录）：
  ```
  python fetch_assets.py --scan
  ```
  若它说本机还没有 → 在 UE 里用 **MetaHuman Creator / Quixel Bridge** 下载任意一个 MetaHuman 到任意工程，再重跑上面这条（以后所有新工程都会自动带上）

---

## 第 5 步：启动（双击即可）

双击 **`deploy\tools\启动管线.bat`**

看到 `[INFO] 编辑器已拉起 pid=...` 且不再滚动报错 = 成功。
引擎窗口会自动移出屏幕；崩了会自动重启续跑，不用管。

**看进度**：浏览器打开 `http://127.0.0.1:8902`（手机同 WiFi 也能看）

---

## 第 6 步：做身份（唯一必须人工的一步）

1. 打开工程：`双击 deploy\tools\打开工程.bat`
2. 等第 5 步的引擎自动导入 `_id` 里的两条 ROM（约 1~2 分钟）
3. 在 UE 里用 MetaHuman Identity 分别给 **am** 和 **pm** 两条 ROM **各做一个身份**并保存
   （成品约 64MB / 每人）
4. 保存后等面板出现身份（或放 `refresh_assets.flag` 强制刷新索引）

> 详细做法见 `docs/全流程测试SOP_am_pm.md`（含截图说明的对应章节）

---

## 第 7 步：绑定（GUI 里点两下）

先编译一次 GUI（只需一次）：
```
cd deploy\ui
dotnet build src\MhsPipeline.App\MhsPipeline.App.csproj
```
然后双击 **`deploy\tools\启动GUI.bat`**，在面板里：

| 操作 | 选择 |
|---|---|
| 身份资产下拉 | 选刚做好的 am 身份 |
| 绑定目标下拉 | 选 `am/` |
| 点 | **[确认绑定]** |
| 再来一次 | pm 身份 → `pm/` → [确认绑定] |

绑定成功后"身份分组"里会出现两行绿色：`am/ → /Game/.../0818_face_rom_am_001_11`

---

## 第 8 步：跑一条，验证出片

把一条表演素材目录（含 `take.json`）拷进：
```
MH_Line01_inbox\am\<某条素材>\
```

然后**等着看**（不用点任何按钮）：

| 时间 | 你该看到 |
|---|---|
| 15 秒内 | 面板"加载中"出现这一条 |
| 2~3 分钟 | 导入完成，进入"处理中"，进度卡显示 Pass / 帧 / 剩余时间 |
| 20~30 分钟 | 完成 → 面板"已完成" + 导出目录出现 FBX |

**验收**：`MH_Line01_out\<am身份名>\<take>.fbx` 存在。

想验证"解算中新拷的不漏"：解算进行中再拷一条到 `MH_Line01_inbox\pm\`，
面板应显示 `[盘] 已到达 · 等待接管`，第一条完成后自动接续。

---

## 收尾

- 优雅停：双击 `停止管线.bat`（跑完当前条再退出，队列保留）
- 只看状态：双击 `查看状态.bat`

---

## 卡住了？三句排查

| 现象 | 做这个 |
|---|---|
| `doctor` 报"编辑器不存在" | 按提示填本机 UE 路径，或 `set MHS_UE_EDITOR=<你的UnrealEditor.exe>` |
| `doctor` 报"工程缺少 MetaHuman 资产" | `python fetch_assets.py --scan` |
| 启动了但一直没动静 | 检查素材是否拷进 `inbox\am\`（不是 `_id`）、目录里有没有 `take.json`；再跑一次 `doctor` |
