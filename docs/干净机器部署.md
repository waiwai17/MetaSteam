# 干净机器部署（换一台电脑从零跑起来）

目标：**只装 UE + Python，其余全部由仓库自带**，clone 完两条命令即可跑通（含测试素材）。

## 0. 前置条件（这两项无法随仓库分发）

| 依赖 | 版本 | 说明 |
|---|---|---|
| Unreal Engine | **5.7**（5.3~5.7 均可，脚本会自动探测） | 必须启用 **MetaHuman** 插件（MetaHuman Animator / Identity 相关） |
| Python | **3.9+**（Windows 安装时勾选 Add to PATH） | 仅用于 launcher/watchdog（GUI 本身是 .NET 9，不需要 Python 才能看界面） |
| .NET 9 SDK | 仅当要**编译 GUI** 时需要 | 不编译则无法用 `启动GUI.bat`（可选） |

> UE 找不到时：`launcher.py doctor` 会提示"未在本机探测到 UE"，或设置环境变量
> `MHS_UE_EDITOR=D:/UE_5.7/Engine/Binaries/Win64/UnrealEditor.exe`。

## 1. 取代码

```
git clone https://github.com/waiwai17/MetaSteam.git
cd MetaSteam
```

## 2. 准备测试素材（仓库自带 am/pm 两条 ID 素材）

```
python tests\fixtures\make_testset.py --out D:\MetaSol\TestLine_inbox
```
生成：
```
<out>\_id\0818_face_rom_am_001_11\     ← 上午(am) 演员的 ROM
<out>\_id\0818_face_rom_pm_001_9\      ← 下午(pm) 演员的 ROM
<out>\am\  <out>\pm\                    ← 表演素材目录（空，待拷）
```
表演素材单条 150~220MB（超过 GitHub 单文件 100MB 上限），**不入库**；如本机有素材库：
```
python tests\fixtures\make_testset.py --out <dir> --with-perf --source E:\Work\Mobu_maya\SSV_Test\Facial_Data
```

## 3. 一键初始化（探测 UE → 建工程 → 建 inbox/out → 写配置）

```
cd deploy\tools
python launcher.py init --name MH_Line01 --dir D:\MetaSol
```
或**直接双击 `启动管线.bat`**（没有配置时会自动走初始化）。

初始化会做：
- 探测本机 `UnrealEditor.exe`（各盘 `UE_5.x` / `Epic Games` 目录）
- 从内置模板 `deploy/template/MH_Template` 复制出新工程（**免编译**，含插件与预编译 DLL）
- 建 `<工程>_inbox\{am,pm,_id}` 与 `<工程>_out`，并复制最新引擎 Python 代码
- 写 `deploy\tools\pipeline.config.json`（**该文件不入库**，是本机运行时配置）

## 4. 预检

```
python launcher.py doctor --config pipeline.config.json
```
应输出 `errors: []`。若报"工程缺少 MetaHuman 资产"：
```
python deploy\tools\fetch_assets.py --from <你已有的参考工程目录>
```
（把 MetaHuman 公共资产复制成本地 `deploy/assets/MetaHumans`，之后所有新工程自动带上）

## 5. 跑起来

- 无头管线：`启动管线.bat`（引擎窗口自动移出屏幕，watchdog 守护）
- 监控面板：先编译一次
  ```
  cd deploy\ui && dotnet build src\MhsPipeline.App\MhsPipeline.App.csproj
  ```
  再 `启动GUI.bat`

## 6. 完整验收（约 1 小时，人工操作约 10 分钟）

1. 启动后 → 把 `_id` 下两个 ROM 拷进 `<工程>_inbox\_id\` → 自动导入
2. 在 UE 里分别制作 **am / pm 两个身份**并保存（成品约 64MB）
3. GUI：身份资产下拉选对应身份 → 绑定目标选 `am/`（和 `pm/`）→ [确认绑定]
4. 拷表演素材到 `<工程>_inbox\am\`（解算中再拷一条到 `pm\` 验证补扫不漏）
5. 交付：`fbx_output\<身份名>\<take>.fbx`

## 常见差异（换机器时）

| 现象 | 原因 / 处理 |
|---|---|
| doctor 报"编辑器不存在" | 配置的 `ue_editor` 是旧机器路径 → 按提示填本机路径（或设 `MHS_UE_EDITOR`） |
| doctor 报"工程缺少 MetaHuman 资产" | 本机没有 MetaHuman 角色资产 → `fetch_assets.py --from <参考工程>` |
| GUI 提示未找到 `tools\launcher.py` | GUI 需与 `deploy\tools` 在同一分发目录内（从 exe 目录逐级向上查找） |
| 启动报"已有编辑器在跑本工程" | 互斥保护；先 `停止管线.bat`，或加 `--adopt` 只接守护权 |
