## 失败排查对照

| 现象 | 先看 |
|---|---|
| 创建失败 | 目标目录是否已存在同名工程 / 模板工程是否还在 `deploy\template\MH_Template` |
| 预检有 errors | 弹窗里逐条列出（编辑器/工程/热文件夹/引导脚本），按提示修 |
| ROM 拷入没反应 | 引擎是否在跑（状态卡"监听中"）、是否拷进 `_id` 子目录、目录里有没有 `take.json` |
| 身份下拉空 | 引擎是否在跑（索引由引擎进程内写）、身份是否真的保存了、点 [刷新] 或放 `refresh_assets.flag` |
| 身份显示"疑似空身份" | 说明没 conform（~0.2MB），回 UE 做完再保存 |
