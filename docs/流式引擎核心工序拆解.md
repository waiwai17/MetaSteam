## 一、技术决策（前提）

| 决策 | 结论 | 依据 |
|---|---|---|
| 运行载体 | 编排核心跑在 **UE 内（Python）** | 导入/解算/导出都是 UE Editor API；独立进程只做监控（Web 数据端） |
| 驱动模型 | **队列消费 + 幂等补扫** | 解算阻塞 34 分钟期间 watcher"失明"无害——素材不消失，段后补扫，幂等保证不漏 |
| 与现有代码 | **复用为主** | 解算链路（`run_depth_shot`/`_on_shot_done`）、幂等（`_is_shot_done`）、文件校验（`precheck_import`）全复用，只新写编排层 |

## 二、就绪判定 · 可插拔占位（⚠ 前序环节未定）

**接口先行，实现可换**：W1 定义统一接口，默认实现为兜底方案；上环节协议/T2 实测确定后换实现，**其他模块零改动**。

```python
# stream_watcher.py —— 就绪判定接口（占位）
class ReadinessRule:
    """就绪判定策略：返回 True=可入队，False=拷贝中/损坏"""
    def is_ready(self, take_dir: str) -> bool: ...
    def describe(self) -> str: ...   # 状态可观测（日志/Web 显示当前用的策略）

# 默认实现（占位）：清单齐 + 短静默期（文件全出现 + 大小 3s 不变）
class DefaultRule(ReadinessRule): ...

# 预留实现（协议确定后即插即用）：
# class DoneMarkerRule(ReadinessRule):   # .done 标记文件（协议版）
# class TempRenameRule(ReadinessRule):   # temp→rename 原子性（若上环节工具支持）
```

**判定原则**（错误代价不对称）：宁可晚判（无害，补扫捞回），不可早判（半拷贝进流水线 = 34 分钟白跑）。

**候选方案全表**（决策依据，详见对话记录 2026-09-18）：

| 方案 | 可靠性 | 配合成本 | 状态 |
|---|---|---|---|
| `.done` 标记文件 | ★★★ | 需协议 | 待上环节 |
| temp→rename 原子性 | ★★★★★ | **零**（若工具支持） | 待 T2 实测 |
| 清单齐 + 短静默期 | ★★★★ | 零 | **默认占位实现** |
| 纯静默期 | ★★ | 零 | 弃用（慢且被网络抖动干扰） |
| 文件句柄探测 | ★★ | 零 | 弃用（杀毒干扰、句柄≠刷盘） |
| 文件系统事件监听 | — | — | 弃用（解决发现速度而非判定准确性） |

## 三、模块拆解

```
热文件夹 ──→ W 发现层 ──→ Q 调度层 ──→ S 观测层 ──→ 面板/Web
```

### W · 发现层（stream_watcher.py）

| 工序 | 内容 | 要点 |
|---|---|---|
| **W1 就绪判定器** | **占位**：`ReadinessRule` 接口 + `DefaultRule`（清单齐+短静默期） | 接口先定死；实现可换 |
| **W2 扫描器** | 轮询热文件夹（默认 5s）；快照 diff 找"新就绪" take；ID 素材识别（`_id/` 子目录约定）；分组解析（`am/`、`pm/` 子目录） | 幂等 diff（已处理的跳过） |
| **W3 入队器** | 新就绪 take → 入队（**入队时快照绑定身份**：按分组查绑定表）；新 ID 制作中到达的表演 → pending 池（超时 30 分钟降级 + 警告） | 上下午问题的核心解法 |

### Q · 调度层（stream_queue.py）

| 工序 | 内容 | 要点 |
|---|---|---|
| **Q1 队列管理器** | 任务结构 `{take目录, 类型, 绑定身份, 状态}`；状态机 `pending→importing→solving→exporting→done/failed`；持久化 `queue_state.json`（原子写） | **崩溃重启队列不丢** |
| **Q2 流水线执行器** | 取队头 → 依次四步（**复用**现有导入/解算/导出链路）→ 完成 → 取下一条 | "取队头"替代现有固定 index 段驱动——C++ 定时器提交逻辑需适配 |
| **Q3 身份/分组管理** | 绑定表维护（Semi：面板 [确认完成] 后写入）；新身份就绪 → 指针切换（**只影响之后入队**）；pending 池超时降级 | 入队时绑定 ≠ 解算时查指针（积压不影响分配） |

### S · 观测层（stream_state.py）

| 工序 | 内容 |
|---|---|
| **S1 stream_state.json 常驻写** | 结构 = Web 原型数据契约（`state/delivered/synced/failed/queued/stage_counts/identity_groups/events`）；状态变化 + 周期 1s 原子写 |
| **S2 [MHS_STREAM] 协议** | 事件行 → C++ `HandleMHLogLine` 解析 → 灌入 Stream Tab（大数字/当前行/四步卡）——面板段间刷新 |

### I · 接口层

| 工序 | 内容 |
|---|---|
| **I1 bridge 入口** | `stream_start / stream_stop`（job_stream.json 驱动） |
| **I2 面板接线** | [开始] → `stream_start`；四步卡/大数字从 S2 灌数 |
